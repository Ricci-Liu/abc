# ABC Browser Circus

This project is a chatroom experiment on how simple grammar syntax could carry meaning.

## How to run

1. Download the repository.

2. Navigate to the project directory
   `cd project`

3. To install dependencies, run the `npm install` command.

4. run `node server.js`,
   If you see HTTPS Server started at port 300X, the server is running.

5. Check the IP address of your local network (for example: 192.168.1.12) and open the following address in your browser:
   https://192.168.1.12:300X

6. Start chatting with your friends!
